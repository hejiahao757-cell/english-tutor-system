# 后续工作交接

当前软件底座已经完成第一阶段：Windows、Android、账号、跨网络同步、题库分类和 9 份 HTML 内容已进入同一工程。接下来的默认优先级重新回到“每日备课内容创作”，除非用户明确要求继续开发软件。

## 开始新一轮备课前

依次阅读：

1. `PROJECT_REQUIREMENTS.md`：不能回退的内容与交互要求；
2. `CONTENT_INVENTORY.md`：已收录内容与分类；
3. `../apps/english-learning-system/src/seed.ts`：软件中的内容登记；
4. 最近一份 U1—U7 密码版 HTML：视觉和功能基线。

## 新增 HTML 的流程

1. 在独立输出目录完成内容创作与浏览器验证；
2. 对照需求检查短横线、隐藏翻译、逐题解析、词卡、打印版和密码前后状态；
3. 将最终文件复制到 `legacy-content`；
4. 在 `src/seed.ts` 登记稳定 ID、标题、分类、范围、标签和文件名；
5. 更新 `CONTENT_INVENTORY.md`；
6. 执行 `npm run build`，确认所有 HTML 都复制到构建产物。

## 不得回退的事项

- 不得从零重做已确认 UI；
- 不得在考试状态提前显示中文、答案或解析；
- 不得用大卡片破坏真实试卷空位；
- 不得遗漏全文翻译和所有单词的中文词卡；
- 不得重复显示完形选项或语法提示词；
- 不得把密码、密钥或个人凭据提交到 Git。
