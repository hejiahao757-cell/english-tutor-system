# Codex Handoff

## 项目目标

将当前英语家教 HTML 原型逐步升级为完整在线英语教学系统。

## 当前阶段

单文件 HTML 原型阶段。

已经完成的核心能力：

- 阅读训练互动化；
- 完形训练互动化；
- 词汇点击卡；
- 生词本；
- 答题记录；
- 学习评价；
- 数据导入导出；
- 响应式布局。

## 下一阶段建议

1. 前端工程化（React/Vue + TypeScript）；
2. 数据模型抽离；
3. 用户登录；
4. 学生档案；
5. 云端同步；
6. 教师后台；
7. AI辅助备课。

## 教学理念

不是单纯背词，而是：

背过 → 在句中认出 → 在文章中理解 → 在题目中得分 → 在陌生文本中迁移。

翻译训练目标不是培养逐词翻译，而是形成英文直接理解能力。
