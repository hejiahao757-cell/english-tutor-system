# 安全说明

- `.env`、教师账号密码、数据库密码、访问令牌、DPAPI 备份和本机 SDK 路径不进入仓库。
- 浏览器、Windows 和 Android 客户端只使用 Supabase 公开 anon key；该 key 本身不是管理员凭据。
- 创建学生等敏感操作通过 Edge Function 执行，数据库访问同时受 Row Level Security 限制。
- HTML 内的课堂解锁密码只能防止学生误触答案，不属于强安全边界；真正的账号与云数据权限由 Supabase 控制。
- 学习痕迹仅保存教学所需的作答、完成状态、生词、页面恢复状态和学习事件，不采集无关个人数据。
- 发现凭据意外提交时，应立即撤销/轮换凭据，再从仓库历史中清理。
