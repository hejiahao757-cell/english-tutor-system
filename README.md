# English Tutor System（英语家教系统）

面向初高中衔接英语家教的交互式备课与训练系统。本仓库汇总了当前 ChatGPT 项目对话中形成的需求、交互原型、词汇材料索引、阅读/完形训练成品以及后续交给 Codex 继续开发所需的上下文。

## 当前可运行版本

推荐从以下文件继续开发：

- `apps/初高中衔接训练_U1-U5_三篇完形_系统底座升级版.html`

这是目前功能最完整的单文件原型，已经包含：

- 三篇不同主题的完形填空；
- 三遍阅读法与逐题折叠解析；
- 四大证据类型：逻辑衔接、人物情感、词义搭配、情节主线；
- 词汇点击卡片、原文语境、生词本；
- 688 / 3500（U1—U5）/ 非背诵范围分类；
- 自动批改与积极型“完形天赋档案”；
- 右侧推出式目录；
- PC / 移动端适配；
- 答题、生词、评价、界面状态的数据导入导出；
- `window.EnglishTutorDataAPI` 前端数据接口。

## 重要口径

- 词汇范围：小学基础词 + 中考核心高频 688 词 + U1—U5 词表。
- 词汇记忆课程负责“背住”；本系统主要负责“在句子、文章、题目中激活和应用”。
- 翻译只作为理解支架，不以逐词翻译为终点。
- 讲解必须服务于学生真实做题过程，强调原文证据、语篇主线、逻辑关系和干扰项识别。
- 学生评价必须积极、有趣、解释充分，不能用负面标签打击学生。

## 数据接口

最新 HTML 暴露：

```js
window.EnglishTutorDataAPI
```

数据按以下模块拆分：

```text
profile / answers / notebook / grading / talent / ui
```

这套结构用于后续接入账号、云端数据库、学生档案、历史记录、教师后台和家长反馈。
